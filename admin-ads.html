How Banner Ads Work

  • Pricing set by admin: You define price for each combination of page + size + duration. Different sizes/pages can have different prices.
  • Various sizes: 728×90, 300×250, 320×50, 468×60, 250×250, 300×600, 970×90, etc. — users pick what they need.
  • Various pages: dashboard, games, tasks, index, profile, etc. — or all for global reach.
  • Various durations: 1 day to 90 days (or custom). Price scales with duration.
  • Empty ads: When no active ad exists for a slot, site shows “Advertise Here” — clicking redirects to place-banner.html with that slot preselected.
  • Base64 images: User uploads image → converted to base64 data URL → stored directly in Firestore (no storage bucket needed). Max 2MB.
  • Moderation flow: User pays → ad enters pending → you Approve (sets start/end dates, live) or Reject (refund).
  • Expiry: After duration, ad becomes expired (auto-checked on render).
